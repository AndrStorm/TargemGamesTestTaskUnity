# Task
1. Create a Unity3d application (2020.3 LTS) with a single stage.\
There should be two arbitrary structures on the stage, consisting of several elements\
(for example, cubes). Both structures must be attracted to some object in the scene\
in such a way that they are guaranteed to collide with each other (but not with the object).\
Inthe event of a collision, structures must fly apart at an arbitrary but sufficiently large distance.\
Also, in case of a collision, it is required to paint the touching structural elements.

3. The user interface consists of a timer, a collision counter, and a button.\
a) The timer should count the time from zero, in seconds.\
b) The collision counter should take into account only collisions of structures as a whole, i.e.\
if several structural elements come into contact during the collision, the counter should increase by one.\
c) The button should reset the timer and counter to the initial value.\
d) The interface must fit on screens with Full HD (1920x1080) and QHD resolution\
(2560x1440) and should not cover the point of attraction.
